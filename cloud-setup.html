☁️ 云端配置

填写 MongoDB Atlas Data API 信息，让任意设备都能注册与访问
获取方法：
1. 注册并登录 cloud.mongodb.com，免费创建 M0 集群；
2. 左侧 App Services → Create App（取个名字如 BaiheApp，区域近你）→ 在创建向导里 Link a data source 选你的 Cluster0；
3. 等 App 部署完（约 1-3 分钟）→ 进入 App → 左侧 Data API → 点 Enable the Data API；
4. 在 Data API 页：API Keys 选项卡 → Create API Key → 复制 Key；CORS / Allowed Origins 添加 https://chenhaijun770528.github.io（或临时填 *）；
5. 回到 Data API 主页，复制顶部的 Endpoint URL（形如 https://data.mongodb-api.com/app/xxx/endpoint，不要包含 /data/v1/action/...）。
集群名（dataSource）默认 Cluster0，数据库名自定义（如 baihe）。
